Nom de l'exercice    : py_graph_cycle_detector
Fichiers attendus    : py_graph_cycle_detector.py
Fonctions autorisées : Aucune
--------------------------------------------------------------------------------

Écris une fonction qui détecte si un graphe orienté contient un cycle.
Le graphe est représenté par une liste d'adjacence.

Ta fonction doit être déclarée comme suit :

def graph_cycle_detector(graph: dict[int, list[int]]) -> bool:

La fonction doit :
- Prendre un graphe sous forme de dictionnaire où les clés sont les nœuds et les valeurs sont des listes de nœuds adjacents
- Retourner True si le graphe contient un cycle, False sinon
- Gérer les graphes vides (retourner False)
- Traiter les boucles sur soi-même (un nœud pointant vers lui-même) comme des cycles

Exemples :

Input: graph_cycle_detector({0: [1], 1: [2], 2: [0]})
Output: True

Input: graph_cycle_detector({0: [1], 1: [2], 2: []})
Output: False

Input: graph_cycle_detector({0: [1, 2], 1: [3], 2: [3], 3: []})
Output: False

Input: graph_cycle_detector({0: [0]})
Output: True

Input: graph_cycle_detector({})
Output: False

Input: graph_cycle_detector({0: [1], 1: [2], 2: [3], 3: [1]})
Output: True

Input: graph_cycle_detector({0: [], 1: [], 2: []})
Output: False
