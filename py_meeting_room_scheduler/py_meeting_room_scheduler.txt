Nom de l'exercice    : py_meeting_room_scheduler
Fichiers attendus    : py_meeting_room_scheduler.py
Fonctions autorisées : Aucune
--------------------------------------------------------------------------------

Écris une fonction qui détermine le nombre minimum de salles de réunion nécessaires
pour planifier toutes les réunions données, et qui retourne l'affectation des salles.

Ta fonction doit être déclarée comme suit :

def meeting_room_scheduler(meetings: list[list[int]]) -> dict[str, any]:

La fonction doit :
- Prendre des réunions sous la forme [[début, fin], ...] où la fin est exclue
- Trouver le nombre minimum de salles nécessaires pour planifier toutes les réunions
- Affecter les réunions aux salles de manière efficace
- Gérer les cas limites : liste de réunions vide, réunions qui se chevauchent

Format de retour :
{
    "rooms_needed": int,
    "room_assignments": dict[int, list[list[int]]]  # ID de la salle -> réunions dans cette salle
}

Exemples :

Input: meeting_room_scheduler([[0, 30], [5, 10], [15, 20]])
Output: {
    "rooms_needed": 2,
    "room_assignments": {
        0: [[0, 30]],
        1: [[5, 10], [15, 20]]
    }
}

Input: meeting_room_scheduler([[9, 10], [9, 12], [11, 13]])
Output: {
    "rooms_needed": 2,
    "room_assignments": {
        0: [[9, 10], [11, 13]],
        1: [[9, 12]]
    }
}

Input: meeting_room_scheduler([[1, 5], [8, 9], [8, 9]])
Output: {
    "rooms_needed": 2,
    "room_assignments": {
        0: [[1, 5], [8, 9]],
        1: [[8, 9]]
    }
}

Input: meeting_room_scheduler([])
Output: {
    "rooms_needed": 0,
    "room_assignments": {}
}

Input: meeting_room_scheduler([[1, 2], [3, 4], [5, 6]])
Output: {
    "rooms_needed": 1,
    "room_assignments": {
        0: [[1, 2], [3, 4], [5, 6]]
    }
}
