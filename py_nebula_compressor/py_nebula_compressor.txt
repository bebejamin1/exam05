py_nebula_compressor

Écris une fonction qui implémente la compression et la décompression par
codage de plages (run-length encoding).
Ta fonction doit être déclarée comme suit :

def nebula_compressor(operation: str, data: str) -> str:

La fonction doit :
	- prendre deux arguments : operation ("compress" ou "decompress") et une chaîne data.
	- pour la compression : remplacer les caractères identiques consécutifs par le caractère suivi du nombre d'occurrences.
	- pour la décompression : redévelopper le format "caractère + nombre" en caractères répétés.
	- retourner "Error" pour une opération invalide
	- gérer correctement les chaînes vides

Règles de compression :
	- si un caractère n'apparaît qu'une seule fois, le laisser tel quel.
	- si un caractère apparaît de 2 à 9 fois consécutivement, le formater en "caractère+nombre"
	- si un caractère apparaît 10 fois ou plus, découper en paquets de 9.

Décompression :
	- le format "caractère+nombre" signifie qu'il faut répéter le caractère ce nombre de fois.
	- les caractères seuls restent inchangés.

exemple :

Input: nebula_compressor("compress", "aaabbc")
output : "a3b2c"

Input: nebula_compressor("compress", "hello")
output : "hel2o"

Input: nebula_compressor("compress", "aaaaaaaaaaaaa")
output : "a9a4"

Input: nebula_compressor("compress", "abcdef")
output : "abcdef"

Input: nebula_compressor("decompress", "a3b2c")
output : "aaabbc"

Input: nebula_compressor("decompress", "hel2o")
output : "hello"

Input: nebula_compressor("decompress", "a9a4")
output : "aaaaaaaaaaaaa"

Input: nebula_compressor("compress", "")
output : ""

Input: nebula_compressor("decompress", "")
output : ""

Input: nebula_compressor("invalid", "test")
output : "Error"
