Nom de l'exercice    : py_prism_detector
Fichiers attendus    : py_prism_detector.py
Fonctions autorisées : Aucune
--------------------------------------------------------------------------------

Écris une fonction qui trouve toutes les occurrences d'un motif (pattern) dans une grille 2D.

Ta fonction doit être déclarée comme suit :

def prism_detector(grid: list[str], pattern: str) -> list[tuple[int, int, str]]:

La fonction doit :
- Prendre une grille 2D (liste de chaînes) et un motif à rechercher
- Chercher dans les 8 directions : horizontale, verticale et diagonale (dans les deux sens)
- Retourner une liste de tuples avec les positions de départ et les codes de direction
- Gérer correctement les grilles vides et les motifs vides
- Retourner une liste vide si aucune occurrence n'est trouvée

Directions de recherche :
- Horizontale (de gauche à droite et de droite à gauche)
- Verticale (de haut en bas et de bas en haut)
- Diagonale (les deux diagonales, dans les deux sens)

Codes de direction :
- "H" = Horizontale (de gauche à droite)
- "H-" = Horizontale (de droite à gauche)
- "V" = Verticale (de haut en bas)
- "V-" = Verticale (de bas en haut)
- "D1" = Diagonale (du coin haut-gauche vers le coin bas-droit)
- "D1-" = Diagonale (du coin bas-droit vers le coin haut-gauche)
- "D2" = Diagonale (du coin haut-droit vers le coin bas-gauche)
- "D2-" = Diagonale (du coin bas-gauche vers le coin haut-droit)

L'ordre de la sortie est basé sur la ligne, puis la colonne, puis le code de direction (dans l'ordre listé ci-dessus).

Exemples :

Input: prism_detector(["ABC", "DEF", "GHI"], "ADG")
Output: [(0, 0, "V")]

Input: prism_detector(["HELLO", "WORLD"], "LL")
Output: [(0, 2, "H")]

Input: prism_detector(["XYZ", "ABC", "DEF"], "XBF")
Output: [(0, 0, "D1")]

Input: prism_detector([], "ABC")
Output: []

Input: prism_detector(["ABC"], "")
Output: []
