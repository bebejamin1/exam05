ATTENTION
Cet exo n'est pas l'officiel, il sert d'entraînement mais il comporte les mêmes attentes que celui d'exam (franchement c'est le même)

Une séquence de transformation du mot beginWord vers le mot endWord à l'aide d'un dictionnaire wordList est une suite de mots beginWord -> s1 -> s2 -> ... -> sk telle que :

Chaque paire de mots adjacents ne diffère que d'une seule lettre.
Chaque si, pour 1 <= i <= k, est présent dans wordList. Notez que beginWord n'a pas besoin d'être dans wordList.
sk == endWord
Étant donné deux mots, beginWord et endWord, ainsi qu'un dictionnaire wordList, retourne le nombre de mots dans la séquence de transformation la plus courte de beginWord à endWord, ou 0 si aucune séquence de ce type n'existe.

Exemple 1 :

Input: beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
Output: 5
Explication : Une séquence de transformation la plus courte est "hit" -> "hot" -> "dot" -> "dog" -> "cog", qui compte 5 mots.

Exemple 2 :

Input: beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log"]
Output: 0
Explication : Le mot endWord "cog" n'est pas dans wordList, il n'existe donc aucune séquence de transformation valide.

Contraintes :

1 <= beginWord.length <= 10
endWord.length == beginWord.length
1 <= wordList.length <= 5000
wordList[i].length == beginWord.length
beginWord, endWord et wordList[i] sont composés de lettres minuscules anglaises.
beginWord != endWord
Tous les mots de wordList sont uniques.
